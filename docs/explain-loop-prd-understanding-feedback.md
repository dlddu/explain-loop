# PRD-4: 이해도 피드백과 다음 설명 반영

## 배경

이해도 점수가 없으면 패턴 선택은 매번 같은 추측을 반복한다. 이 PRD는 설명마다 이해도를 가볍게 받고,
그 점수를 설명에 쓰인 패턴에 귀속시켜 집계한 뒤, 다음 패턴 선택(PRD-3)의 증거로 되돌려 보내는 **학습 루프**를 다룬다.

## 이해도 척도 (5점, 앵커 포함)

같은 숫자가 매번 같은 뜻을 갖도록, 점수마다 "무엇을 할 수 있는가"로 앵커를 둔다.

| 점수 | 앵커 | 학습자 입장 표현 |
|------|------|------------------|
| 1 | 이해 못함 | 무슨 말인지 모르겠다 |
| 2 | 조각만 이해 | 단어는 알겠는데 연결이 안 된다 |
| 3 | 큰 그림 이해 | 대략 알겠는데 내 말로는 설명 못 하겠다 |
| 4 | 설명 가능 | 내 말로 다시 설명할 수 있다 |
| 5 | 적용 가능 | 이걸로 다른 문제에 써먹을 수 있다 |

## 달성 가치
- **V2: 쓸수록 나아지는 설명** — 점수를 패턴에 귀속·집계하고 다음 선택에 반영한다.
- **V5: 부담 없는 피드백** — 점수 입력을 1회 조작으로 끝낸다.
- **V1: 이해로 끝나는 설명** — 낮은 점수를 받은 주제는 다른 방식으로 다시 설명하게 한다.
- **V3: 설명 방식의 근거가 남는다** — 점수가 설명·선택 기록·패턴 버전까지 추적된다.

## Acceptance Criteria

### AC4.1: 1회 조작 입력
- **설명**: 설명 직후 이해도 입력 수단이 제공되고, 점수 하나를 고르는 것만으로 저장이 끝난다.
  코멘트와 막힌 지점(AC4.3)은 선택 사항이며 입력하지 않아도 저장을 막지 않는다.
- **달성 가치**: V5
- **검증 방법**: 설명 수신 후 점수 1개 선택 외 아무 조작 없이 점수가 저장되는지 확인

### AC4.2: 앵커가 보이는 척도
- **설명**: 점수를 입력할 때 각 점수의 앵커(위 표)가 함께 보인다.
- **달성 가치**: V5, V2
- **검증 방법**: 입력 화면/프롬프트에 1–5 각각의 앵커 문구가 표시되는지 확인

### AC4.3: 막힌 지점 지정 (선택)
- **설명**: 학습자는 설명의 특정 구간을 "여기서 막힘"으로 지정할 수 있고,
  지정된 구간에 적용된 패턴(PRD-3 AC3.7)에 막힘이 기록된다.
- **달성 가치**: V2, V1
- **검증 방법**: 비유 구간을 막힘으로 지정 → `analogy` 패턴의 막힘 횟수가 1 증가하는지 확인

### AC4.4: 귀속과 미평가 구분
- **설명**: 점수는 `explanation_id`에 연결되어 선택 기록과 패턴 버전까지 추적된다.
  점수가 입력되지 않은 설명은 `미평가`로 남고, 집계에서 0점이나 낮은 점수로 취급되지 않는다.
  점수를 수정하면 이력이 보존되고 집계에는 최신 값이 쓰인다.
- **달성 가치**: V2, V3
- **검증 방법**: 점수 → 설명 → 선택 → 패턴 버전 경로 조회 확인. 미평가 설명이 평균에 포함되지 않는지, 수정 시 이력과 최신값 반영 확인

### AC4.5: 학습자×패턴 집계
- **설명**: 학습자별·패턴별로 평균 이해 점수, 표본 수, 막힘 횟수, 최근 사용 시점이 집계된다.
  설명 1건의 점수는 그 설명에 **적용된** 모든 패턴에 귀속된다("미적용" 표시된 패턴은 제외).
- **달성 가치**: V2
- **검증 방법**: 알려진 점수 데이터셋을 넣고 집계 결과를 손 계산 결과와 대조

### AC4.6: 다음 선택에 반영
- **설명**: 집계가 다음 요청의 학습자 스냅샷(PRD-2 AC2.3)에 포함되고, 패턴 선택 근거가 이를 증거로 인용한다.
  - 해당 학습자에게 성과가 낮은 패턴(평균 ≤ 2.0, 표본 ≥ 3)을 다시 고르면 재선택 사유가 필수다.
  - 같은 주제 재요청(PRD-2 AC2.6)에서 이전 설명의 점수가 3 미만이면, 이전과 다른 패턴을 1개 이상 포함한다.
  - 임계값(2.0, 3건, 3점)은 초기값이며 조정 가능하다.
- **달성 가치**: V2, V1
- **검증 방법**: 저성과 패턴이 있는 학습자의 다음 선택 근거에 집계 인용과 재선택 사유가 있는지, 저점수 주제 재요청 시 패턴 조합이 달라지는지 확인

### AC4.7: 탐색 보장과 콜드 스타트
- **설명**: 높은 점수의 패턴 조합에만 고착되지 않도록, 표본이 적은 패턴을 일정 비율로 시도하고
  해당 선택을 `mode: explore`로 표시한다 (초기값: 설명 5건 중 약 1건).
  평가 데이터가 전혀 없는 학습자는 `mode: cold_start`로 선택하고 근거에 "데이터 없음"을 명시한다.
- **달성 가치**: V2
- **검증 방법**: 동일 학습자로 설명 20건 생성 시 `explore` 비율이 설정값 근처인지, 신규 학습자 첫 선택이 `cold_start`인지 확인

### AC4.8: 학습 추이 조회
- **설명**: 학습자별 이해 점수 추이, V2 지표(최초 10건 평균 vs 최근 10건 평균), V5 지표(응답률)를 조회할 수 있다.
- **달성 가치**: V2, V5
- **검증 방법**: 알려진 점수 이력으로 조회한 지표가 손 계산 결과와 일치하는지 확인
