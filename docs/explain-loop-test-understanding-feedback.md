# 테스트 문서 T4: 이해도 피드백과 다음 설명 반영

## 검증 대상 AC
- AC4.1: 1회 조작 입력 (PRD-4)
- AC4.2: 앵커가 보이는 척도 (PRD-4)
- AC4.3: 막힌 지점 지정 (PRD-4)
- AC4.4: 귀속과 미평가 구분 (PRD-4)
- AC4.5: 학습자×패턴 집계 (PRD-4)
- AC4.6: 다음 선택에 반영 (PRD-4)
- AC4.7: 탐색 보장과 콜드 스타트 (PRD-4)
- AC4.8: 학습 추이 조회 (PRD-4)

## 테스트 시나리오

### T4-S1: 한 번에 끝나는 점수 입력
- **사전 조건**: 학습자 L1이 설명 E1을 방금 받음
- **실행 단계**: 1) 입력 수단 확인 2) 점수 4만 선택, 코멘트·막힌 지점 입력 없음
- **기대 결과**: 1) 1–5 각각 앵커 문구가 함께 표시 2) 추가 조작 없이 E1의 점수 4 저장
- **검증 AC**: AC4.1, AC4.2

### T4-S2: 막힌 지점 귀속
- **사전 조건**: E2의 구간 2가 `analogy`, 구간 3이 `sequence-diagram`으로 매핑됨
- **실행 단계**: 점수 2 입력과 함께 구간 2를 "여기서 막힘"으로 지정
- **기대 결과**: L1의 `analogy` 막힘 횟수 +1, `sequence-diagram` 막힘 횟수 변화 없음
- **검증 AC**: AC4.3

### T4-S3: 추적 경로·미평가·수정 이력
- **사전 조건**: E1(점수 4), E3(점수 미입력)
- **실행 단계**: 1) E1 점수에서 설명 → 선택 → 패턴 버전까지 조회 2) L1 평균 점수 조회 3) E1 점수를 4→3으로 수정 후 이력·평균 조회
- **기대 결과**: 1) 경로 끝까지 조회됨 2) E3은 `미평가`, 평균에서 제외 3) 이력에 4와 3 모두 남고 평균은 3 기준
- **검증 AC**: AC4.4

### T4-S4: 집계 정확성
- **사전 조건**: 학습자 L1에 대해 아래 데이터 주입
  - E10: 적용 `level`, `analogy` / 점수 2
  - E11: 적용 `level`, `analogy`, `visualization` / 점수 4
  - E12: 적용 `level` / 선택됐지만 `analogy` "미적용" / 점수 5
- **실행 단계**: L1×패턴 집계 조회
- **기대 결과**: `level` 평균 3.67(표본 3), `analogy` 평균 3.0(표본 2, E12 제외), `visualization` 4.0(표본 1)
- **검증 AC**: AC4.5

### T4-S5: 저성과 패턴과 저점수 재요청 (루프 종단 시나리오)
- **사전 조건**: L1의 `storytelling` 평균 1.67(표본 3). L1이 주제 X를 `level`+`structured-toc`로 설명받고 점수 2
- **실행 단계**: 1) `storytelling` `use_when`에 맞는 새 요청 처리 2) 주제 X 재요청 처리
- **기대 결과**:
  1) 선택 근거가 L1의 `storytelling` 집계를 증거로 인용. `storytelling`을 다시 골랐다면 재선택 사유 필수
  2) 새 요청 컨텍스트에 E(주제 X)가 연결되고(AC2.6), 새 선택에 `level`·`structured-toc` 외 패턴이 1개 이상 포함, 근거가 이전 점수 2를 인용
- **검증 AC**: AC4.6

### T4-S6: 탐색 비율과 콜드 스타트
- **사전 조건**: 탐색 비율 설정 20%. 평가 데이터가 충분한 L1, 신규 학습자 L2
- **실행 단계**: 1) L1으로 설명 20건 생성 2) L2 첫 요청 처리
- **기대 결과**: 1) `mode: explore` 선택이 약 4건(허용 범위 2–6건), 탐색 선택은 표본이 적은 패턴을 포함 2) `mode: cold_start`, 근거에 "데이터 없음"
- **검증 AC**: AC4.7

### T4-S7: 추이와 가치 지표
- **사전 조건**: L1의 평가된 설명 20건 — 최초 10건 평균 2.8, 최근 10건 평균 3.6. 평가 가능 설명 25건 중 20건 응답
- **실행 단계**: L1 학습 추이 조회
- **기대 결과**: 점수 시계열 표시, V2 지표 +0.8(목표 +0.5 충족), V5 응답률 80%(목표 60% 충족)
- **검증 AC**: AC4.8
