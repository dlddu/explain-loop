# 테스트 문서 T3: 패턴 선택·근거 저장·설명 생성

## 검증 대상 AC
- AC3.1: 선택이 생성보다 먼저 (PRD-3)
- AC3.2: 증거가 있는 근거 (PRD-3)
- AC3.3: 탈락 후보 기록 (PRD-3)
- AC3.4: 프레이밍 먼저 (PRD-3)
- AC3.5: 활성 패턴과 버전 고정 (PRD-3)
- AC3.6: 패턴 관계 준수 (PRD-3)
- AC3.7: 패턴이 추적되는 설명 (PRD-3)
- AC3.8: 사용자 지정 패턴 우선 (PRD-3)

## 테스트 시나리오

### T3-S1: 선택 기록 없이는 설명 없음
- **사전 조건**: 시드 세트, 학습자 L1
- **실행 단계**: 1) 선택 기록 저장소 쓰기를 실패하도록 설정하고 요청 처리 2) 설정 복구 후 같은 요청 처리
- **기대 결과**: 1) 설명이 저장되지 않고 오류 보고 2) 설명 저장, `selection.created_at < explanation.generated_at`, 설명의 `selection_id`가 해당 선택을 가리킴
- **검증 AC**: AC3.1

### T3-S2: 근거의 증거 검사
- **사전 조건**: 평가 데이터가 있는 학습자 L1, 신규 학습자 L2
- **실행 단계**: 1) L1 요청 처리 후 선택 기록 조회 2) 증거 없이 "일반적으로 효과적"만 적힌 선택 저장 시도 3) L2 첫 요청 처리
- **기대 결과**: 1) 모든 `selected[]`에 `evidence` ≥ 1, 참조 대상 실재 2) 저장 거부 3) `mode: cold_start`, 근거에 "데이터 없음" 명시와 `use_when` 증거 허용
- **검증 AC**: AC3.2

### T3-S3: 탈락 후보와 사유
- **사전 조건**: `pros-cons`, `structured-toc`, `storytelling`의 `use_when`에 모두 해당하는 요청("REST랑 GraphQL 뭐가 나아?")
- **실행 단계**: 요청 처리 후 `rejected[]` 조회
- **기대 결과**: 탈락 후보 ≥ 1, 각각 사유 있음 (예: "`storytelling` 제외 — 비교 판단이 목적")
- **검증 AC**: AC3.3

### T3-S4: 프레이밍 포함 규칙
- **사전 조건**: 시드 세트
- **실행 단계**: 1) 일반 요청("Kafka가 뭐야?") 처리 2) "설명 말고 ERD만 그려줘" 요청 처리
- **기대 결과**: 1) `framing` 패턴 ≥ 1 포함 2) `framing` 없이 `erd`만 선택 가능하되 사유("사용자가 다이어그램만 요청") 기록
- **검증 AC**: AC3.4

### T3-S5: 폐기 패턴 제외·버전 기록
- **사전 조건**: `storytelling` 폐기, `analogy` v3
- **실행 단계**: 1) "이야기처럼 쉽게 풀어줘"(storytelling `use_when` 정확히 해당) 요청 2) 비유가 필요한 요청
- **기대 결과**: 1) `storytelling` 미선택 2) `analogy` 선택 기록의 `version`이 3
- **검증 AC**: AC3.5

### T3-S6: requires·conflicts 준수
- **사전 조건**: 테스트용 패턴 A, B를 `A conflicts_with B`로 등록. 학습자 L1(배경 지식 없음), L3(배경 지식 "Java 개발자")
- **실행 단계**: 1) L1 요청에서 `analogy` 선택 유도 2) L3 요청에서 `analogy` 선택 유도 3) A와 B 동시 선택 저장 시도
- **기대 결과**: 1) `background-probe` 함께 선택 2) `background-probe` 생략 가능, 생략 사유("스냅샷에 배경 지식 있음") 기록 3) 거부
- **검증 AC**: AC3.6

### T3-S7: 구간–패턴 매핑
- **사전 조건**: `goal-setting`, `analogy`, `sequence-diagram`이 선택되는 요청
- **실행 단계**: 설명 생성 후 `segments[]` 조회
- **기대 결과**: 각 선택 패턴이 ≥ 1개 구간에 매핑되거나 "미적용" 표시. 어떤 구간도 선택 목록 밖 패턴을 가리키지 않음
- **검증 AC**: AC3.7

### T3-S8: 사용자 지정 패턴
- **사전 조건**: `sequence-diagram` 등록됨, `mind-map` 미등록
- **실행 단계**: 1) "시퀀스 다이어그램으로 설명해줘" 요청 2) "마인드맵으로 설명해줘" 요청
- **기대 결과**: 1) `sequence-diagram` 포함, `mode: user_override`, 근거 증거에 사용자 요청 원문 2) 미등록 안내와 `mind-map` 패턴 등록 제안
- **검증 AC**: AC3.8
